Para executar este algoritmo é necessário instalar a biblioteca igraph:

 ->   python -m pip install igraph

 O Codigo calcula o tempo minimo de um vertice que o usuario vai digitar na entrada para todos os outros (Usando o algoritmo de dijkstra).

 A entrada usada de teste no "grafo.txt" é referente ao grafo passado em aula no slide 12 -> "grafo_exemplo.png"


Saida esperada desse grafo com a entrada "1" (menor distancia do vertice 1 para todos os outros):

Menor distancia do vertice 1 -> 1 = 0

Menor distancia do vertice 1 -> 2 = 1

Menor distancia do vertice 1 -> 3 = 2

Menor distancia do vertice 1 -> 4 = 3

Menor distancia do vertice 1 -> 5 = 2
